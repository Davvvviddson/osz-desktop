# OSz Changelog

## 5.0 — Visual system and wallpaper library
- Reworked the four desktop environments with more deliberate layout, typography, surfaces, window treatments, taskbars/dock/launcher, controls, and responsive behavior.
- Refined app surfaces including Settings, App Store, Calculator, Calendar, File Explorer, Browser, and Paint Studio.
- Added a Wallpaper Library section in Settings with live SFW Wallhaven API search and one-tap image application.
- Added source links for MotionBGS, MoeWalls, and Wallhaven.
- Added custom image URL and MP4/WebM video wallpaper support, plus local video selection for the current browser session.
- Preserved the existing `projectX.desktop.v1` local-storage namespace and existing OSz features.

## 4.1 — Visual refresh
- Added distinct Windows-inspired, macOS-inspired, Linux-inspired, and OSz Custom desktop themes.

## 4.0 — Workspace features
- Added notification center, multiple app instances, persistent Paint Studio artwork, and keyboard shortcuts.

## OSz 6.0
- Added PC-style window management, desktop context menu, task view, Run dialog, and calendar flyout.
- Added keyboard shortcuts and refined system tray/taskbar behavior.
- Updated visual hierarchy and responsive desktop shell styling.
