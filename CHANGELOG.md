# OSz Desktop Changelog

## 4.0.0
- Added a notification center with unread indicators, timestamps, dismiss controls, and clear-all.
- Added multiple instances of the same app, each with its own taskbar item.
- Added notification events for new files, calendar entries, and clearing Paint Studio.
- Paint Studio artwork now autosaves locally and restores on the next launch.
- Added PNG export for Paint Studio drawings.
- Added Paint Studio to the desktop launcher.
- Added Ctrl/Command + Space to open Start and Escape to dismiss open panels.
- Updated first-run copy and documentation for OSz 4.0.

## 3.2.0
- OSz branding update based on the Project X desktop simulator.


## 4.1 — Desktop visual refresh
- Reworked Windows, macOS, Linux, and OSz Custom desktop palettes, wallpapers, panels, docks, window chrome, and widgets.
- Added subtle CSS-only texture and hover transitions.
- Kept all desktop artwork original and self-contained; no third-party website imagery is embedded.
- Preserved existing app behavior and local storage namespace.
